# منارتك — الواجهة العامة فقط

هذه نسخة خفيفة من الواجهة العامة الحالية مع صورها وملفاتها والحزم المشتركة اللازمة لها. استُبعدت لوحة الإدارة، والواجهة الخلفية المستقلة، وأرشيف صور التصميم وجلسات AI Studio، ووثائق وإعدادات المشروع الكامل غير اللازمة لتشغيل الواجهة.

لم يتغير أي ملف داخل `apps/web/` أو الحزم المشتركة عن النسخة المرتبة في المستودع. إعدادات البيانات والصور هي إعدادات النسخة الأصلية. جُهز ملف `package.json` في الجذر بأوامر تشغيل خاصة بهذه الحزمة، دون تعديل اعتماديات الواجهة.

## التشغيل

استخدم Node.js حديثًا متوافقًا مع Vite، ثم من داخل هذا المجلد:

```sh
npm install
npm run dev
```

افتح http://localhost:3000 .

## البناء والمعاينة

```sh
npm run build
npm run preview
```

ناتج البناء في `apps/web/dist/`، والمعاينة على http://localhost:4173 .

لا تتضمن الحزمة `node_modules` أو ملفات البناء. النسخة الكاملة في مستودع `wegdangamil2022-oss/MANARATAK22` لم تتغير.
