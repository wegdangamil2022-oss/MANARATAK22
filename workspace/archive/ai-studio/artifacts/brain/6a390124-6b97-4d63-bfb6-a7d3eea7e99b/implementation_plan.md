# تحديثات تصميم منحة الحكومة الصينية (CSC)

تم تطبيق التعديلات المطلوبة بدقة على صفحة منحة الحكومة الصينية مع الحفاظ الكامل على التصميم الأصلي وجميع ألوان وترتيب المنصة:

1. **قسم الشروط ومعايير التقديم**:
   - استبدال نقاط شروط التقديم بأيقونة **«جوهرة فيروزية مدمجة» (B-03)** المعين الفيروزي-البترولي المتدرج بقلب أبيض ناصع.

2. **بطاقة جامعة تسينغهوا (Tsinghua University)**:
   - تخصيص أيقونة الصرح الجامعي بلون **«بترولي الأفق المنفرد الصافي» (#0E7C86)**.

3. **تنويع الخطوط العلوية قبل الأقسام في المنحة الصينية**:
   - خط نيلي المنارة الصافي (`LINE-01`: `#142B5F`).
   - خط بترولي الأفق الصافي (`LINE-02`: `#0E7C86`).
   - خط فيروزي الإشراق الصافي (`LINE-03`: `#21A7B4`).
   - خطوط متدرجة مدمجة (`LINE-07`: نيلي ← بترولي ← فيروزي، و`LINE-08`: نيلي ← ذهبي ← بترولي).
