# تقرير ترتيب المشروع

التاريخ: 2026-11-10، بتوقيت عدن.

المصدر: `manaratak-design (1).zip` المرفق من المستخدم.
المستودع المستهدف بطلب المستخدم: `wegdangamil2022-oss/MANARATAK22`، الفرع `main`.

## التغييرات

- جُمعت إعدادات Vitest وفحص الأنواع الموجودة في الجذر داخل `config/testing/`، مع تحديث الاستيرادات وأوامر GitHub Actions التي تشير إليها. تبقى أوامر الاختبارات من جذر المشروع كما كانت.
- نُقل دليل IELTS إلى `docs/guides/`.
- حُفظ الملف التعريفي الأصلي دون تعديل في `docs/archive/README.original.md`، وأُضيف وصف مختصر للنسخة المرفقة وهيكلها الحالي في الجذر.
- نُقلت ملفات AI Studio المؤقتة إلى `workspace/archive/ai-studio/` مع حفظ محتواها الأصلي كاملًا.
- نُقلت الصور المرجعية الموجودة في `public/assets/` إلى `workspace/archive/design-reference-assets/`. مرجع الصورة الوحيد من هذا المجلد في شيفرة التطبيق كان داخل صفحة التصميم المحذوفة؛ صور الواجهة الحالية موجودة في بياناتها وداخل `apps/web/public/` ولم تُنقل أو تُعدل.
- حُذف ملف `ManaratakDesignShowcase.tsx`، واستيراده وعرضه وزر فتحه في الصفحة الرئيسية، وأُزيل اختياره من نوع التنقل. هذا هو التصميم الذي حدده المستخدم للحذف.

لم تتغير صور المنح، أو مكونات بطاقاتها، أو ألوان الواجهة الحالية، أو بياناتها، أو `package.json`، أو `bun.lock`، أو إعدادات Vite، أو ملفات API ولوحة الإدارة والحزم المشتركة.

## التحقق

- **نجح بناء الواجهة الأصلية وبناء الواجهة بعد الترتيب** بواسطة Vite 6.4.6، باستخدام إعدادات Vite الأصلية دون تعديل:

  ```sh
  node node_modules/vite/bin/vite.js build --config apps/web/vite.config.ts
  ```

- **نجحت 11 حالة اختبار** في ملفي الاختبارات الموجودين أصلًا، عبر الإعداد المنقول إلى مكانه الجديد:

  ```sh
  node node_modules/vitest/vitest.mjs run apps/web/tests/remediation/HomeCatalogDesignPhotos.spec.tsx apps/web/tests/remediation/HomeCatalogCards.spec.tsx --config config/testing/home-catalog-vitest.config.ts
  ```

- **نجح فحص المتصفح** على ناتج البناء في Chrome دون واجهة مرئية، بعرضي 390 و1440 بكسل: بطاقتا المنح تختاران روابط الصور الأصلية، وصفحة التصميم الإضافية وزر فتحها غير ظاهرين، ولا توجد أخطاء JavaScript غير معالجة.
- **نجحت مطابقة الملفات** وبصماتها وفحص استيرادات الإعدادات المنقولة.

استُخدمت اعتماديات تحقق محلية منفصلة (ومنها Vitest 3.2.4 وreact-test-renderer 19.3.1)، دون تعديل اعتماديات المشروع أو ملف قفله. أدوات التحقق و`node_modules` وملفات البناء ولقطات المتصفح ليست ضمن المشروع المسلم.

## حدود النسخة الأصلية

يحتوي الملف المرفق على وثائق وملفات GitHub Actions تاريخية تشير إلى مجلدات وأوامر غير مرفقة، مثل `scripts/` و`tests/` في الجذر وبعض تنفيذات الحزم المشتركة. كما لا يحتوي على `package-lock.json`، وبعض أدوات الاختبارات غير معرفة ضمن اعتمادياته. لم تُستكمل هذه الأجزاء أو تُغير وظائف المشروع ضمن مهمة ترتيب الملفات.

نتائج التحقق المحلي، عند تسجيلها أعلاه، تخص الواجهة والاختبارات المذكورة فقط، ولا تعني اكتمال اختبارات API أو لوحة الإدارة أو الجاهزية للنشر.
